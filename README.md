# 공개 의약품 데이터로 본 시장의 선행 신호와 수요

> 이 파일은 S7·T5에서 완성한다. 아래는 골격이다. 숫자는 파이프라인 결과로만 채운다.

## 두 프로젝트
| | P1 선행 신호 원장 | P2 수요 예측 |
|---|---|---|
| 질문 | 급여목록 비고의 예정 정보는 실제 변화로 얼마나, 얼마 만에 이어지나 | 성분×시도 원외처방 수요를 얼마나 맞출 수 있고, 선행 신호가 도움이 되나 |
| 데이터 | 심평원 급여목록·대체조제 목록 스냅샷 2022-01~2025-12, 건보공단 사용통계 | 건보공단 사용통계 2018-01~2025-12, P1 신호 |
| 결과 | (S4) | (T3·T4) |
| 자동화 | `make report MONTH=YYYY-MM` 월간 선행 신호 리포트 | 롤링 평가, 발주 시뮬레이션 |

## 재현
```
pip install -r requirements.txt
make all
```

## 한계
(S7·T5에서 작성: 약국 단위 자료 없음, 업체 2곳 이하 성분 비공개, 2026 속성표의 생존 편향 등)
- 제품 역할(`product_role`)은 공개 목록의 대조약·생동인정·오렌지북 표시로만 정한다. **대조약이 항상 오리지널은 아니다.** 근거가 없는 제품은 "모름"이다.
