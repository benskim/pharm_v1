# P2 v2 최종 분석 설계 (사용자 결정 반영, 사전등록 확정 전)

> 상태: **§9 사용자 결정 반영(2026-11-20, DECISIONS 'P2 v2 설계 결정').** 코드 구현·분석 실행은 아직 승인되지 않았다. 코드·시험·자료·결과를 바꾸지 않았고, 커밋·태그도 하지 않았다. 2026년 자료는 열지 않았다. §9-2 확인 필요도 답함(2026-11-20).
> 기준 커밋: 9c7743a (v1.2). 작성 2026-11-20.
> 만든 과정: ① 독립 설계 에이전트가 v1 코드·결론을 전제로 두지 않고 설계안을 냈다 → [reports/P2V2_design_independent.md](../reports/P2V2_design_independent.md). ② 별도 검증 에이전트가 비판적으로 검토했다(수정 권고 33개, 높음 8) → [reports/P2V2_design_review.md](../reports/P2V2_design_review.md). ③ 두 결과를 비교해 이 문서를 썼다. 권고별 처리는 §3.
> 사전등록 문서 초안: [docs/PREREG_P2V2.md](PREREG_P2V2.md). 커버리지·검출력·dry run을 거쳐 사용자가 승인한 뒤에만 고정(태그)한다.
> 용어: a = 마지막 관측월, M = 예측 시점(발간월), t = 예측 대상월, h = t − a. 공개 시차 5개월 가정에서 M = a + 5, 주 조건 h = 6 → t = M + 1.

## 1. 기존 P2(v1)의 문제점 (요약)

자세한 표는 독립 설계안 §1(F1 ~ F16). 핵심만 옮긴다.

| # | 문제 | v2 대응 |
|---|---|---|
| F1 | 대상 선정에 미래 정보(96개월 관측, 평가 기간 계절성으로 고른 분류, 2022 전체 규모) | 선정 기준 시점 a₀ = 2022-07, 그때까지 자료로만 선정 |
| F2 | 단위가 섞인 수량 순위·합계(정·mL·g를 더함) | 크기·순위·가중은 원외 청구**금액**. 오차는 성분 안에서만 수량으로 |
| F3 | 결과를 본 뒤 대상 확장, 헤드라인 교체 | 처음부터 넓은 대상, 사전등록 + 코드 잠금 |
| F4 | 비교 기준 1개(작년 같은 달) — 기준 해 이상과 모델 우위가 구분 안 됨 | 기준 3개를 모두 이겨야 "나음", 기간 견고성을 판정 조건에 |
| F5 | 주 지표·주 검정 미지정, 헤드라인 숫자와 검정한 양이 다름 | 주 지표 하나, 그 지표 차이를 평균으로 갖는 계열에 DM 하나 |
| F6 | 신호 특징이 2022 이전 NaN이라 시기 표시로 작동 | 목록 정보는 기본 모델에 넣지 않고 별도 층(목록이 있는 기간만) |
| F7·F8 | 신호(비고 미래 날짜)만 써서 목록에 이미 보인 가격 변화를 놓침, 목표(수량)와 정보(가격)의 기전 불일치 | 목록 고시 원칙으로 정보 집합을 넓히고, Q2 주를 단가 예측으로 |
| F9 | 검출력 미설계 | 사전 시뮬레이션 검출력, 사전 정한 가짜 효과·주입 시험 |
| F10 | 수정본 자료 하나 — 최근 수준 의존 모델에 유리 | 고칠 수 없음. 모든 결론에 "(수정본 자료로 평가)", Stage 4와 판본 쌓기로 |
| F11 | "다음 달" 표기 혼동 | a·M·t·h 표기, 공개 시차 0 결과 없음 |
| F12 | 결과를 보며 진단 갈래 추가 | 보조 분석 목록을 사전등록으로 닫음, 밖은 '사후 탐색' |
| F13 | 잠근 시간 holdout 없음 | Stage 4(2026)가 규칙까지 포함한 첫 시간 holdout |
| F14·F15·F16 | 코로나 표시만, L2 손실, 해석 불가 재고 시뮬레이션 | 기간 표시 재설계, L1 손실, 재고 시뮬레이션 제외 |

**독립성의 한계(미리 밝힘)**: 2023–2025는 v1이 이미 본 기간이다. 설계 선택 일부(기준 해 이상 표시, 목표 log(y_t / y_{t−12}), Q2를 가격 쪽으로 둔 것)는 v1 결과를 아는 상태에서 정해졌다. 그래서 2023–2025 백테스트는 **완전한 맹검이 아니고**, 맹검 평가는 Stage 4뿐이다. 이 문장을 모든 결과 보고서의 "먼저 읽을 한계" 첫머리에 둔다.

## 2. 사업적 질문과 주장 범위

- 자료: 전국 성분(주성분 4자리) 단위 원외 처방 청구, 약 5개월 늦게 공개, 수정본 판 하나. **약국 발주용 자료가 아니다.**
- **주 용도**: 성분 시장 모니터링 — 6개월 앞(공개 시차 5개월 가정) 성분 원외 처방 수준. 유통·플랫폼이 자체 거래 자료를 가지면 "전국 시장 대비" 지표의 분모.
- 참고 용도(검정하지 않음, 실시간 아님): 공개 공백 5개월의 현재 수준 추정(h = 1 ~ 5).
- 가격·급여정지 위험 알림은 P1의 몫이다.

| 검증할 주장 | 검증하지 않는 주장 (결론에 쓰지 않음) |
|---|---|
| Q1. 6개월 앞 성분 원외 청구수량 예측에서 모델이 세 단순 기준보다 금액 가중 오차가 작은가 | 약국·지역 단위 수요, 재고 최적화, 결품 감소 |
| Q1 보조. 그 차이가 연도별(2023 / 2024 / 2025)로 어떤가 | 제품별 수요·성분 안 처방 이동 |
| Q2. origin에 보이는 급여목록 가격 경로가 성분 청구 **단가** 예측을 사용통계만 쓴 단가 예측보다 낫게 하는가 | 가격 인하가 처방량을 바꿨다는 주장(전후 변화·연관만) |
| Q2 보조. 같은 정보가 수량 예측을 낫게 하는가, 그 시험이 일부러 넣은 효과를 찾는가 | 실시간(초본) 정확도, 절감액, 도매 유통 |
| 예측 거리 1 ~ 12개월 오차 곡선(기술 통계) | 플랫폼 자체 자료가 예측을 낫게 할지 |
| Stage 4. 2023–2025의 우열 방향이 2026-01 ~ 06에서 반대가 아닌가 | 2026 오차 수준과 2023–2025 수준의 비교 |

## 5. 최종 설계

### 5-1. 분석 단위와 대상
- 단위: **성분(주성분 4자리) × 전국 × 월, 원외.** 제품은 자료에 없고, 약효분류군은 수량을 더할 수 없어 쓰지 않는다. 시도는 범위 밖.

### 5-6. 질문 2: 급여목록 정보

**원칙**: 목록 ≤ M만. 목록 고시 원칙(RULES §3): 목록 M에 처음 보인 변화는 비고 날짜가 없어도 M 1일 시행 예고다. a ~ M 사이 목록 상태로 확인되는 가격 변화는 **관측된 상태(이벤트)**, M+1 이후 날짜가 적힌 비고는 **신호(예고)**다. **신호는 예측값에 곱하지 않고 특징으로만 쓴다**(CLAUDE.md 핵심 원칙, PLAN_P2 §1, DECISIONS 2026-11-19).

**정보 정의** (성분 c, origin M = a + 5, 대상월 t, 제품 집합 P_c(m) = 목록월 m `state_as_known`이 급여인 제품 중 성분4가 c, 가격 p_j(m) = `price_listed`):

| 기호 | 정의 | 종류 |
|---|---|---|
| ΔK_c | P_c(a) ∩ P_c(M)(같은 제품코드) 제품마다 log(p_j(M) / p_j(a))의 산술평균(제품 같은 무게) | 관측된 상태 |
| ΔN_c | M 목록에 그 예고 비고가 **남아 있는** 제품의 가격 예고 중 시행일 ∈ (M 1일, t 말일], origin에 집행정지 표시가 보이지 않는 것. 제품마다 ω_j · log(예고 금액 / p_j(M)), ω_j = t월 안 시행일 이후 날 수 ÷ t월 날 수(t 이전 달 시행이면 1). P_c(M) 제품 수로 나눈 평균(예고 없는 제품 0) | 신호 |
| ρ_M | build_asof(M) 원장에서 확인 달 ≤ M인 약가 예고의 정시 실현 비율(제품 단위). 계산 불가면 1 | 과거 실현율 |
| 보조 특징 | ΔF(업체 수 변화), ΔP(급여 제품 수 변화), S(급여정지·중지 상태 비율), SN(급여정지·중지 예정 비율, 시행일 ≤ t, 집행정지 없음), LN(등재 예고 수 log1p) | 관측·신호 |

- 제품 같은 무게(판매량이 없음). 코드가 바뀐 제품은 같은 제품코드가 아니면 ΔK에서 빠진다(이어받기 연결은 §9 Q12).

**Q2 주 (정보 시험): 성분 단가 예측** — 수량 오차와 섞이지 않게 단가만 비교한다.
- 정답: UP_ct = A_ct / y_ct.
- **U1 (목록 정보)**: ÛP_ct = UP_ca · exp(ΔK_c). 전가율 1 고정(매개변수 없음).
- **U0 (사용통계만, 단가 추세 연장)**: ÛP_ct = UP_ca · (UP_ca / UP_{c,a−12})^{(t−a)/12}.
- 지표: 금액 가중 단가 절대 로그오차 = Σ_i w_i · mean_t |log ÛP_it − log UP_it|. 대상월 분해 d_t = Σ_i w_i |log ÛP_it − log UP_it| / T_i(T_i = 성분 i의 평가 칸 수). 검정·판정은 §5-8 그대로(U1 대 U0, 보정 없음).
- 해석 범위: "목록에 이미 보인 가격 경로가 성분 청구 단가를 사용통계 추세보다 잘 따라가는가." 처방량이 가격에 반응했다는 뜻이 아니다.

**Q2 점검·보조**
- Q2-a 회계 점검(판정 아님): 금액 F1K = ŷ^G · UP_ca · exp(ΔK) 대 F0 = ŷ^G · UP_ca. 기대 방향이 분명하므로 "확인"으로만.

### 5-7. 평가 지표
- 평가 칸 E_Q1 = {(i, t): t ∈ 평가 기간, 정답 관측, B1·B2·B3·G 모두 예측}. **하나의 공통 집합**으로 모든 Q1 비교. E_Q2 = E_Q1 ∩ {UP_ca, UP_{c,a−12}, ΔK 정의}.
- 성분 오차 WAPE_i = Σ_{t∈E_i} |y_it − ŷ_it| ÷ Σ_{t∈E_i} y_it.
- **주 지표(Q1)**: 금액 가중 WAPE = Σ_i w_i · WAPE_i, w_i = 성분 i의 **2018-12 ~ 2019-11** 원외 청구금액 ÷ 대상 합(사용자 결정 2026-11-20, 사전 고정, 칸이 빠져도 바꾸지 않음). Q2의 금액 가중도 같은 w_i.
- 대상월 분해: 금액 가중 WAPE = Σ_t d_t, d_t = Σ_i w_i |y_it − ŷ_it| ÷ Y_i. ΔWAPE = Σ_t (d_t^A − d_t^B).
- 보조(판정 아님): 비가중 상대 오차(r_i = WAPE_i^A / WAPE_i^B의 기하평균·중앙값·r_i < 1 비율), 부호 있는 오차(편향), 연도별, 하위 집단 H, 예측 거리 곡선, 목표 건수·금액.
- 쓰지 않는 것: MASE, 성분끼리 수량을 더한 합계 WAPE.
- **요약 첫 줄(헤드라인)** = 주 판정 문구 + 전체 기간 금액 가중 WAPE(B1·B2·B3·G) + 각 차이의 90% 구간. 연도별·H는 본문 표에만.

### 5-8. 통계적 판정
- 계열 D_t = T · (d_t^A − d_t^B), t = 2023-01 ~ 2025-12, T = 36. 평균 D̄ = ΔWAPE.
- **주 검정 (2026-11-20 사용자 결정, 검증 V1 ~ V6 통과 뒤 승인 — `reports/P2V2_ewc_check_result.md`)**: EWC(equal-weighted cosine, Lazarus·Lewis·Stock·Watson 2018). Ω̂ = (1/ν) Σ_{j=1}^{ν} Λ_j², Λ_j = √(2/T) Σ_t cos(πj(t − ½)/T)(D_t − D̄), 통계량 D̄ / √(Ω̂/T), t(ν), 양측 α = 0.05, **ν = round(0.4·T^{2/3})**: Q1·Q2 주(T = 36) ν = 4, Q2-d(T = 24) ν = 3. Stage 4에서는 p값을 내지 않는다(부호 일치만 보고, 2026-11-20 사용자 결정). Ω̂ ≤ 1e-14·mean(D²)이거나 계열에 NaN이 있으면 판정 = 판단 보류(기록). 90% 구간 = D̄ ± t_{0.95}(ν)·√(Ω̂/T)(주 검정과 같은 기반). **민감도(판정에 쓰지 않음, 결과와 주 검정과의 차이를 공개)**: ① DM — 가중 없는 지연 0 ~ 5 자기공분산 합, 통계량 × HLN 계수 √((T + 1 − 2h + h(h−1)/T)/T), t(T − 1)(분산 ≤ 0이면 Bartlett 5) ② Bartlett 12, t(T − 1). **검정끼리 결론이 달라도 자동으로 판단 보류하지 않는다.** 공식 판정은 검증된 주 검정 하나로 낸다(이전 "두 p가 갈리면 판단 보류" 규칙은 삭제). 근거: 감사 `reports/P2V2_dm_audit.md` — T = 36에서 DM + HLN의 거짓 '나음' 6.2 ~ 6.8%, Bartlett 12 + t(35) 7.9 ~ 9.3%(명목 한쪽 2.5%), EWC ν = 4는 2.2 ~ 2.7%.
- **판정(비교 하나마다)**, δ = **0.5%p**(금액 가중 WAPE 절대 차이, 사용자 결정 2026-11-20, §9 Q5). Q2 주 지표에는 **로그오차 0.005**(사용자 결정 2026-11-20):

| 판정 | 조건 |
|---|---|
| **나음** | D̄ < 0, p < 0.05, **그리고 R1·R2 모두 D̄ < 0** |
| **나쁨** | D̄ > 0, p < 0.05, 그리고 R1·R2 모두 D̄ > 0 |
| **기간 의존 — 판단 보류** | p < 0.05이지만 R1 또는 R2에서 부호가 다름 |
| **동등** | 위가 아니고 90% 구간이 (−δ, +δ) 안 (TOST) |
| **판단 보류** | 나머지 |

  '나음'인데 90% 구간 상한 > −δ면 "나음(실무 여유 안)"으로 표시.
- **Q1 종합**: "단순 예측보다 나음" = G 대 B1·B2·B3 **세 비교 모두 '나음'**(교집합-합집합). 종합이 '나음'이면 개별 문장은 원 p, 아니면 개별 문장은 Holm(3) p. 그 밖의 종합 문구: "가장 강한 기준과 동등"(가장 강한 기준 = 평가 기간 금액 가중 WAPE가 가장 작은 B), "가장 강한 기준보다 나쁨", "판단 보류".
- Q2 주(U1 대 U0)는 단일 비교, 보정 없음. Q1과 Q2는 각각 α = 0.05.
- 보조 검정(판정 아님): 원형 이동 블록 부트스트랩(블록 12개월, 9,999회) 95% 구간, 성분별 r_i < 1 비율(p값 없음, 성분 독립 아님 — 유의성을 부풀린다는 점을 적음).
- 검정하지 않는 것: 연도별·H·예측 거리별·보조 목표 차이(표로만, "유의"라는 말을 쓰지 않음).
- **사전 검출력**: 평가 기간 정답을 쓰지 않는 시뮬레이션 — **2020-06** ~ 2022-12 대상월(31개월)에서 B2의 대상월 분해 계열로 자기상관 구조를 추정하고(사용자 결정 2026-11-20: 처음 적은 2019-07은 B2의 24개월 입력 조건(a − 23 ≥ 2018-01) 때문에 계산할 수 없어 B2가 계산되는 첫 대상월로 고침. 영향: 창이 대부분 코로나·회복기라 평가 기간의 분산과 다를 수 있음. 가중치 기간 2018-12 ~ 2019-11·A18 2021-08 ~ 2022-07은 바꾸지 않음), 그 구조로 T = 36 계열을 만들어 ΔWAPE = −δ, −2δ일 때 검출률을 사전등록 문서에 적는다. 못 하면 "사전 검출력 미산정"으로 적는다. 결과 뒤 구간 폭은 '구간 폭 환산'으로만 보고.
- 사전 예상(사전등록에 적음): 기준 3개를 모두 이겨야 하고 T = 36이라 **Q1 종합은 '판단 보류'가 될 가능성이 높다.**
