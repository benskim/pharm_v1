# PLAN_P2 — 성분×시도 원외처방 수요 예측과 발주 시뮬레이션 (2026-11-14)

## 1. 목표와 주장

**질문**: 공개 사용통계만으로 성분별·지역별 다음 1~3개월 원외처방 수요를 얼마나 맞출 수 있는가. P1의 선행 신호를 넣으면 나아지는가. 그 예측으로 발주하면 결품과 과잉재고가 줄어드는가.

**주장의 형태**: "신호를 넣으면 개선된다"를 미리 정하지 않는다. 개선이 없으면 그대로 보고한다. 신호는 예측값에 직접 반영하지 않고 **특징으로만** 넣는다 (CLAUDE.md 핵심 원칙).

| 항목 | 값 |
|---|---|
| 목표 변수 | 원외 청구수량 (보조: 청구건수) |
| 단위 | 성분 4자리 × 시도 × 월. 전국 = 시도 합 |
| 기간 | 2018-01 ~ 2025-12 (96개월) |
| 예측 시점 (origin) | 2023-01 ~ 2025-09 (매월) |
| 예측 기간 | 1, 2, 3개월 앞 |
| 데이터에 없는 것 | 약국 단위 구매·재고·판매. 일반의약품(비급여). 업체 2곳 이하 성분 |

## 2. 대상 성분

1. **관측 조건**: 2018-01~2025-12 전국 기준 96개월 내내 관측된 성분 (비공개로 빠진 달이 없음). 중간에 나타난 성분은 별도 표로만 보고한다.
2. **규모 조건**: 2022년 원외 청구수량 상위 성분. 개수는 `config/params.yaml`의 `p2_top_n` (기본 200).
3. **주력 묶음** (2026-11-14 확정): 급여목록 `분류` **141, 222, 229, 618**. 114는 겨울/여름 비율 1.05로 계절성이 없어 "나머지"에 두고, 계절 묶음과 비계절 묶음의 대조군으로 쓴다. 614(2022 원외 수량 0.74억, 1.182)와 619(96개월 관측 성분 1~2개)는 넣지 않는다. 겨울/여름 비율 = 2022~2025 원외 청구수량의 겨울(11~3월) 월평균 ÷ 여름(6~8월) 월평균 (`DECISIONS.md`).
4. **기관 범위**: 기본은 전체 요양기관의 원외. 보조 분석으로 의원급 원외만 따로 (약국 수요에 가장 가까운 대리변수). 요양기관종별 코드는 S0에서 확인한다.

커버리지 보고: 대상 성분 수, 전체 원외 청구금액 중 비중, 비공개로 빠진 성분의 목록 기준 비중.

## 3. 특징

| 묶음 | 특징 | 사용 가능 기간 | 누수 규칙 |
|---|---|---|---|
| 자기 시차 | 시차 h..h+11, 12개월 전, 이동평균 | 전체 | 예측 기간 h보다 가까운 시차 금지 |
| 달력 | 월, 영업일 수, 설·추석이 든 달 | 전체 | 달력은 미리 알 수 있음 |
| 구조 | 시도, 성분의 약효분류, 연령 구성비(직전 12개월) | 전체 | 직전 값만 |
| **선행 신호** (P1) | 예고 인하 폭 × 제품 비중 × 노출 일수, 등재 예정 업체 수, 급여정지 제품 수, 유효 업체 수 변화 | 2022-01 ~ | **M월 스냅샷에서 만든 신호 특징은 M+1월 이후의 origin에서만 쓴다** (사용자 결정 2026-11-14 9차. 스냅샷의 기준일은 명목 날짜이고 그 달 안의 이후 정보가 들어 있을 수 있다) |
| 외부 (선택) | 독감 의사환자 분율 (주별 → 월) | 파일 확보 시 | origin 이전 주까지 |

**공개 시차**: 실제 업무에서는 사용통계가 몇 달 늦게 나온다. `config/params.yaml`의 `usage_publication_lag_months`를 두고 0(이상적)과 현실값 두 가지로 평가한다. 현실값은 사용자가 `DECISIONS.md`에 정한다.

## 4. 모델

| ID | 모델 | 신호 |
|---|---|---|
| M0 | 계절 단순 예측 (12개월 전 값) | 없음 |
| M1 | ETS (시계열별) | 없음 |
| M2 | LightGBM 전역 모델 (전 시계열 한 모델) | 없음 |
| M3 | M2 + 선행 신호 특징 | 있음 |

- M2와 M3는 같은 하이퍼파라미터·같은 시드. 비교는 신호가 있는 기간(origin 2023-01 이후)에서만 한다.
- 계층 정합 (선택): 시도 예측의 합 = 전국 예측이 되도록 MinT(shrink)로 맞춘다. 정합 전후 오차를 같이 보고한다.
- 분위 예측: M2/M3의 P50·P90 (분위 회귀 또는 conformal). 구간 포함률을 보고한다.

## 5. 평가

- 시간순 롤링 origin. 학습은 origin 이전 데이터만.
- 지표: MASE (계절 척도 12), WAPE, 분위 예측은 pinball loss와 P90 포함률.
- 나눠서 보고: 예측 기간별, 독감 유행기(11~3월)와 비유행기, 신호가 있던 성분·월과 없던 성분·월, 주력 묶음과 나머지.
- 코로나 시기 (2020~2021): 학습에는 포함하되 플래그 특징을 둔다. 이 시기를 origin으로 한 평가는 따로 보고한다 (본 비교에는 넣지 않음).
- M3 대 M2의 차이는 성분별 오차 차이에 대한 부호 검정 또는 Diebold-Mariano 검정으로 본다. 유의하지 않으면 "차이 없음"으로 쓴다.

## 6. 발주 시뮬레이션

**설정**: 시도 × 성분마다 가상의 창고 하나. 월 1회 검토, 리드타임 1개월. 발주 목표 = 다음 달 예측 분위수 − 현재 재고.

| 정책 | 발주 기준 |
|---|---|
| 기준 | M0 예측 × (1 + 고정 안전계수) |
| 예측 기반 | M2 또는 M3의 분위수 (분위 수준은 결품·재고 비용 비율에서 정함) |

- 결과: 결품률(수요 대비 부족분 비율), 평균 재고일수, 둘의 교환 곡선. 비용 비율 여러 값에 대해.
- 실제 수요는 사용통계 실측값으로 둔다.
- **한계를 결과보다 먼저 쓴다**: 약국 단위가 아니다. 리드타임·비용 비율은 가정이다. 시도 합계의 변동은 개별 약국보다 훨씬 작다.

## 7. 단계와 완료 기준

S0은 P1과 공통이다 (`PLAN_P1.md` §6).

| 단계 | 내용 | 완료 기준 |
|---|---|---|
| **T1** 예측 마트 | `fc_panel` (성분×시도×월), 대상 성분 선정, 커버리지 표 | 원본 재집계 합 = 마트 합. 첫 관측월 제외 규칙 테스트. 대상 선정 기준과 탈락 단계표 |
| **T2** 기준선 | M0, M1, 롤링 평가 틀 | 누수 테스트 통과 (미래 행을 바꿔도 과거 origin 예측이 안 바뀜). 오차표 |
| **T3** 전역 모델·신호 | M2, M3, 신호 특징 (P1 S3 이후) | **T3 비교용 상한** (10차): M3를 "M월 파일을 M월 origin부터 사용"과 "M+1월 origin부터 사용" 두 기준으로 돌려 차이를 보고한다. 앞의 것은 미래 정보가 섞인 비교용 상한이고, **결과로는 뒤의 것만 쓴다.** 신호 특징 누수 테스트 (origin O의 특징은 O−1월까지의 스냅샷만으로 만든다: O월 이후 스냅샷을 지워도 특징 동일. 나중에 고쳐 쓴 `exposure_frac`을 쓰지 않고 origin 시점의 `signal_ledger` 행만 쓰는 경우 포함). M3 대 M2 비교표와 검정 |
| **T4** 분위·발주 | 분위 예측, 정합(선택), 발주 시뮬레이션 | P90 포함률 보고. 정책별 교환 곡선. 한계 절 먼저 |
| **T5** 문서 | README 절, 2쪽 요약 | 개선이 없던 결과도 요약에 포함 |

**최소판** (시간이 부족할 때): 주력 묶음 성분 × 전국, M0·M2·M3, 1개월 앞. 발주 시뮬레이션은 한 가지 비용 비율.

## 8. 바로팜 공고와의 대응

| 공고 문구 | 근거 산출물 |
|---|---|
| 약국 구매, 판매, 사용 패턴 분석 기반 예측 모델 개발 | M2·M3, 의원급 원외 보조 분석. 약국 단위 자료가 없음을 먼저 밝힌다 |
