# PLAN P2 v3 — 분류군별 예측 오차와 사용 패턴 비교 (P2 첨부 별도 분석)

작성 2026-11-24, 실행 전 고정. 사용자 지시: "약효분류 2자리 버전, ATC 2단계 버전 각각으로 비교분석. 가장 예측력이 높은 그룹부터 낮은 그룹까지 모두 나열. 예측력 외에 사용패턴(계절성, 추세, 잔차 변동성 등) 대표지표도 출력."

## 1. 위치와 성격
- P2 v2 **백테스트 주 결과에 붙이는 별도 분석**이다. P2 v2 사전등록 목록 밖이며 **사후 탐색**이다. 판정(나음·나쁨)을 내리지 않는다.
- P2 v2의 예측·대상·가중치·잠금 코드는 읽기만 한다. 새 예측을 만들지 않는다. Stage 4(2026 대상월) 결과는 쓰지 않는다.
- 코드 `src/pbd/forecast_v3/`, 실행 `make p2v3-group`, 시험 `tests/test_p2v3_group.py`, 출력 `outputs/p2v3/`, 보고 `reports/P2v3_group_result.md`.

## 2. 입력
| 입력 | 쓰는 것 |
|---|---|
| `outputs/p2v2/backtest/predictions.csv` | h = 6, 대상월 2023-01 ~ 2025-12, 모델 G·B1·B2·B3 (B0은 참고라 쓰지 않음) |
| `outputs/p2v2/backtest/dropped_cells.csv` | 평가 칸에서 뺄 칸(재등장 첫 달) |
| `outputs/p2v2/target.csv` | 대상 501개 성분, `cls3`(2022-07 급여목록 제품 수 최다 분류), 가중치 `w` |
| `fc_panel` (pbd.duckdb) | 정답 원외 청구수량, 사용 패턴 계열 |
| `attr_2026_product` (pbd.duckdb) | 2026 약가정보의 9자리 제품코드 × ATC (속성표로만, DATA.md) |
| `stg_benefit` 2022-07 | 성분 대표 이름(표시용) |

## 3. 평가 칸과 오차 (P2 v2 §5-7 그대로)
- 평가 칸 E = {(i, t): 2023-01 ≤ t ≤ 2025-12, 정답 관측·> 0, G·B1·B2·B3 모두 예측, dropped_cells 아님}. 전체 금액 가중 WAPE가 P2 v2 verdict 값과 같아야 한다(재현 확인).
- 성분 오차 WAPE_i = Σ_t |y − ŷ| ÷ Σ_t y. 편향 bias_i = Σ_t (ŷ − y) ÷ Σ_t y.
- 분류군 g 오차 = Σ_{i∈g} w_i WAPE_i ÷ Σ_{i∈g} w_i (가중치를 분류군 안에서 다시 정규화, P2 v2 A4와 같은 방식). 성분끼리 수량을 더하지 않는다.

## 4. 분류군 배정
- **약효분류 2자리(cls2)** = `cls3` 앞 2자리.
- **ATC 2단계(atc2)** = ATC 앞 3자리(예: C09). 성분4마다 `attr_2026_product`에서 성분코드 앞 4자리가 같은 제품의 ATC 2단계 중 **서로 다른 제품코드 수가 가장 많은 값**(사용자 결정 2026-11-24). 같으면 코드가 작은 값. ATC가 `^[A-Z][0-9]{2}` 형식이 아니면 세지 않는다. 연결되는 제품이 없으면 `미연결` 군.
- 성분에 ATC 2단계가 둘 이상 있으면 `atc2_n`·`atc2_top_share`(최다 값의 제품 몫)를 남긴다.

## 5. 분류군 표 (cls2, atc2 각각)
- 성분 수, 가중치 몫, 평가 칸 수, 대표 성분(가중치 상위 3), 최대 성분의 군 안 가중치 몫.
- 모델별 분류군 오차(G, B3, B1, B2), 군 안 최저 오차 모델, G의 B1·B3 대비 개선률 = 1 − 오차_G ÷ 오차_기준.
- G의 성분 WAPE 중앙값·사분위, G 편향(가중).
- G 분류군 오차의 90% 구간: 군 안 성분 재표집 2,000회(시드 `seed`). 성분 1개 군은 구간 없음.
- **순위 = G 분류군 오차 오름차순(1 = 오차가 가장 작음).** 성분 3개 미만 군(2026-11-24 사용자 결정, 처음 5개)은 `small_group = true`로 표시하고 모두 나열한다.

## 6. 사용 패턴 지표 (성분마다, 원외 청구수량)
창 = **2023-01 ~ 2025-12**(평가 기간과 같음, 코로나 시기 제외). 36개월 모두 관측·> 0인 성분만 계산(결측을 채우지 않음), 아니면 빈칸과 사유.
| 지표 | 정의 |
|---|---|
| 계절성 강도 | log y에 STL(주기 12, robust) → max(0, 1 − Var(R) ÷ Var(S + R)) |
| 추세 강도 | max(0, 1 − Var(R) ÷ Var(T + R)) |
| 연간 증가율 | log y를 월 번호에 최소제곱 직선 적합, exp(12 × 기울기) − 1 |
| 잔차 변동성 | STL 잔차의 표준편차(log 척도, 약 % 변동) |
| 겨울/여름 비율 | 11~3월 월평균 ÷ 6~8월 월평균 (DECISIONS 2026-11-14의 정의를 이 창에 적용) |
| 전년 동월비 변동성 | sd(log(y_t ÷ y_{t−12})), t ∈ 창 (2022 달을 비교 대상으로 씀) |
- 분류군 요약: 지표별 중앙값과 가중 평균(w).
- 분류군 차이: 성분 3개 이상 군끼리(처음 5개) Kruskal–Wallis H, p, ε² = H ÷ (n − 1). G의 WAPE_i에도 같은 시험. 서술용이며 판정이 아니다.
- 성분 단위 연관: G의 WAPE_i와 각 패턴 지표의 Spearman 상관.

## 7. 쓰는 말
- "예측력이 높다" 대신 표에서는 "오차가 작다". 분류군·패턴과 오차는 "연관"으로만 쓴다. 약효가 오차의 원인이라고 쓰지 않는다.
- 오차는 수정본 사용통계로 평가했고 최근 달은 덜 집계되었을 수 있다(LIMITATIONS W4). 2023–2025는 v1이 이미 본 기간이다.

## 8. 변경 (2026-11-24, 사용자 지시, 실행 전 기록)
- **ATC 연결 확대**: `attr_2026_product` 대신 2026 약가정보 `표준코드` 4~12자리(= 9자리 제품코드) → 2022-01 ~ 2025-12 급여목록 주성분코드 → 성분4. 제품 수 최다 규칙은 그대로. 이전 경로와의 차이를 `atc2_path_diff.csv`에 남긴다.
- **작은 군 합치기**: 성분 3개 미만 원래 군 → `{상위}_기타`(상위 = 약효분류 첫 자리, ATC 1단계 = 첫 글자). 합친 기타 군도 3개 미만이면 `전체_기타`. 순위·시험·군간 몫은 합친 군으로 한다.
- **초점 = 군간 차이** (군별 예측 모델 실험의 사전 자료): 군간 몫 η²_w = Σ_g W_g(ē_g − ē)² ÷ Σ_i w_i(e_i − ē)²(가중치 w), 우연 기준 (군 수 − 1) ÷ (성분 수 − 1)과 함께. 대상: G·B3 오차(log 포함), 모델 차이 G − B3·G − B1(군마다 우열이 다른지), 패턴 지표. 군 표에 전체 대비 차이와 G − B3를 둔다. 군별 모델 실험 자체는 하지 않는다.

## 9. 다시 묶기 (2026-11-24, 사용자 지시)
질문: ATC 2단계 군을 (a) ATC 1단계로, (b) 사용 패턴이 비슷한 것끼리 묶으면 군간 차이가 커지는가. 코드 `src/pbd/forecast_v3/regroup.py`, 실행 `make p2v3-regroup`, 출력 `outputs/p2v3/regroup/`, 보고 `reports/P2v3_regroup_result.md`.
- 합친 묶음의 η²는 원래 군보다 커질 수 없으므로(군간 몫은 합치면 줄거나 같다) 두 가지로 본다: ① 블록 순열 = ATC 2단계 군을 통째로 같은 수의 묶음에 무작위 배정한 것 대비 초과(ATC 1단계는 원래 ATC 2단계 군, 패턴 군집은 합친 군이 블록), ② 성분 순열 대비 초과로 군 수가 다른 분류끼리 비교. 순열 999회, 시드 `seed`.
- 평가 지표: G 오차 log, B3 오차 log, 모델 우열 log(WAPE_G ÷ WAPE_B3)·log(WAPE_G ÷ WAPE_B1), 패턴 지표. 가중(w)과 비가중 둘 다. 원 척도 차이 G − B3는 극단값에 끌려 참고만.
- 패턴 군집: ATC 2단계 군(합친 군)마다 성분 패턴 중앙값(계절성 강도, 추세 강도, 연간 증가율, 잔차 sd, 겨울/여름) → 표준화 → Ward. 전년비 sd는 G·B1 목표와 정의가 겹쳐 뺀다. 군 수 4, 6, 8, 14(ATC 1단계 수), 22(약효분류 2자리 수)를 미리 정해 모두 보고.
- **주 창 = 2018-01 ~ 2022-07**(P2 v2 선정 기준 시점 a₀까지, 군별 모델 실험에서 쓸 수 있는 정보). 평가 기간 창(2023-01 ~ 2025-12)으로 묶은 것은 참고(평가 정보를 씀). 같은 창의 패턴으로 묶고 같은 패턴을 재는 칸은 `circular`로 표시하고 본문에 쓰지 않는다.

## 10. 혼합 묶음 (2026-11-24, 사용자 지시)
질문: ATC 2단계의 장점을 살리면서 차이가 거의 없는 군만 ATC 1단계로 묶는 방식과 다른 혼합 방식을 ATC 2단계·ATC 1단계와 비교. 코드 `src/pbd/forecast_v3/hybrid.py`, `make p2v3-hybrid`, 출력 `outputs/p2v3/hybrid/`, 보고 `reports/P2v3_hybrid_result.md`.
- 출발 = 원래 ATC 2단계(69개). 모든 혼합은 ATC 1단계 경계 안에서만 합치고, 합친 뒤 성분 3개 미만 묶음은 같은 ATC 1단계 안 가장 가까운 묶음에 붙인다.
- H1 패턴 유사(2018-01 ~ 2022-07 패턴), H2 2022 오차 유사(모델 우열), 문턱 τ = 같은 ATC 1단계 군 쌍 거리 25·50·75% 분위수, 평균 연결. H3 크기(성분 5·10개 이상 유지, 나머지 `{ATC1}_기타`), H4 크기 + 패턴(나머지를 패턴이 가장 가까운 큰 군에).
- 평가 = 2023-01 ~ 2025-12 오차. 주 지표 모델 우열 log(G/B3)의 군간 몫. 비교: 원래 ATC 2단계 대비 유지율, 군 수 보정 η², ATC 1단계 안에서 원래 군을 같은 구조로 무작위 합친 것 대비 초과(층 안 블록 순열 999회).

## 11. 부분 풀링 비교 (2026-11-24, 사용자 지시)
코드 `src/pbd/forecast_v3/pooling.py`, `make p2v3-pooling`, 출력 `outputs/p2v3/pooling/`, 보고 `reports/P2v3_pooling_result.md`.
- 부분 풀링 = 두 단계 경험적 베이즈: ATC 1단계 평균을 전체 쪽으로, ATC 2단계(원래 69개) 평균을 그 ATC 1단계 추정 쪽으로 줄임. b = τ² ÷ (τ² + σ² ÷ 유효 성분 수). ATC 2단계 τ²는 적률법과 DerSimonian–Laird(정밀도 가중) 두 가지, ATC 1단계 τ²는 적률법.
- 풀링은 η²를 낼 수 없어 모든 방식(원래·합친 ATC 2단계, ATC 1단계, 약효분류 2자리, H1~H4, 풀링 2개)을 **한 성분 빼고 맞히기 R²**로 비교(LOO마다 τ²·σ² 다시 추정). 딱 잘라 나눈 묶음의 예측 = 같은 묶음의 다른 성분 가중 평균, 혼자면 전체 평균.
- 차이의 90% 구간: 성분 재표집 2,000회(예측 고정, 시드 `seed`). 기준 = 원래 ATC 2단계, 풀링(DL).
- 큰 군 기준은 성분 수(사용자 결정). 학습 행 수 제안은 철회(성분 수와 순위 상관 0.996).

## 12. 모델 우위의 시점 일관성 (2026-11-24, 사용자 지시, 실행 전 고정)
질문: 성분 수가 충분하고 홀드아웃·연도별로도 특정 모델(B3 ETS, B1) 우위가 일관된 군이 있는가. 코드 `src/pbd/forecast_v3/consistency.py`, `make p2v3-consistency`, 보고 `reports/P2v3_consistency_result.md`.
- 군: 원래 ATC 2단계(주), 원래 약효분류 2자리(보조), 성분 5개 이상. Δ = 군 G 오차 − 군 A 오차(군 안 금액 가중 WAPE), 양수 = A가 나음.
- 일관 우위 = ① 성분 ≥ 5 ② 발견 2022-01 ~ 2023-12 Δ > 0 ③ 홀드아웃 2024-01 ~ 2025-12 Δ > 0 ④ 2023·2024·2025 모두 Δ > 0 ⑤ 홀드아웃 Δ 90% 구간(군 안 성분 재표집 2,000회) 하한 > 0.
- 우연 기준: 군 표지 섞기(크기 유지) 999회로 ②~④ 통과 군 수. 부분 풀링: 홀드아웃 성분별 log(G/A)의 DL 경험적 베이즈 군 추정을 함께 보고.
