## 1. 가설 (방향을 미리 기대하지 않는다)
- **H1 (Q1)**: 6개월 앞(공개 시차 5개월 가정) 성분 원외 청구수량 예측에서 G의 금액 가중 WAPE가 B1·B2·B3 각각보다 작다.
- **H2 (Q2 주)**: origin에 보이는 급여목록 가격 변화(ΔK, 목록 고시 원칙)를 반영한 단가 예측 U1이 사용통계 단가 추세 U0보다 금액 가중 단가 절대 로그오차가 작다.
- **H3 (Q2-d 보조)**: 목록 정보 보정층 F1q가 F0q′보다 수량 금액 가중 WAPE가 작다. 주입 20%를 회수하지 못하면 판정하지 않는다.
- 사전 예상: 기준 3개를 모두 이겨야 하고 T = 36이라 H1 종합은 '판단 보류'가 될 가능성이 높다. H3은 '효과를 찾을 힘이 없음'으로 끝날 가능성이 높다.

## 5. 모델 설정 (PLAN §5-3·§5-4·§5-6 그대로)
- B1, B2, B3(statsmodels ETS, log, 오차·계절 가법, 추세 {없음, 가법 감쇠} AICc, 대체 규칙과 10% 상한). B0는 참고.
- G: LightGBM 전역 직접, 목표 log(y_t / y_{t−12}), l1, 특징 {g1, g3, seas, size, mon, dwork, lunar, cls2, cov_base, cov_anchor}, 하이퍼파라미터 PLAN §5-4, 조정 없음, 시드 20261114, 학습 대상월 τ ≥ 2019-09.

## 6. 주 지표
- Q1: 금액 가중 WAPE = Σ_i w_i Σ_t |y_it − ŷ_it| / Y_i (수량, 성분 안에서만).
- Q2 주: 금액 가중 단가 절대 로그오차 = Σ_i w_i · mean_t |log ÛP_it − log UP_it|.
- 헤드라인 = 주 판정 문구 + 전체 기간 지표(B1·B2·B3·G) + 차이의 90% 구간.

## 7. 주 검정과 판정
- D_t = T(d_t^A − d_t^B). DM: 분산 = 지연 0 ~ 5 자기공분산 가중 없는 합(≤ 0이면 Bartlett 5) × HLN, t(T − 1), 양측 α = 0.05. 견고성 p = Bartlett 대역폭 12. 두 p의 판정이 갈리면 '판단 보류'.
- 동등 여유 δ = **0.5%p**(Q1 금액 가중 WAPE 절대 차이, 사용자 결정 Q5). Q2 주 지표 δ = **로그오차 0.005**.
- 판정: **나음** = D̄ < 0, p < 0.05, R1·R2 모두 D̄ < 0 / **나쁨** = 대칭 / **기간 의존 — 판단 보류** = p < 0.05이나 R1 또는 R2 부호가 다름 / **동등** = 90% 구간 ⊂ (−δ, +δ) / **판단 보류** = 나머지. '나음'이고 90% 상한 > −δ면 "나음(실무 여유 안)".
- H1 종합: 세 비교 모두 '나음'일 때만 "단순 예측보다 나음". 종합이 '나음'이면 개별 문장은 원 p, 아니면 Holm(3). 가장 강한 기준 = 평가 기간 지표가 가장 작은 B.
- H2: 단일 비교(보정 없음). 시점 이동 가짜(7·17개월) 두 판 모두보다 U1이 '나음'이 아니면 "시점 정렬의 기여 확인 안 됨". 순열(ΔK ≠ 0 성분끼리 999회) p ≥ 0.05면 "성분별 정렬의 기여 확인 안 됨".
- H3: 주입 20%에서 F1q가 F0q′보다 '나음'이 아니면 판정 안 함.
- 사전 검출력: `<문장 확정 대기 — 3단계 결과 §4·§7 확인 필요 3>`. 계산값: 단일 비교 '나음' 비율 ΔWAPE = −δ 12 ~ 16%, −2δ 25 ~ 31%, 차이 0에서 5.0 ~ 5.7%. Q2는 미산정(사전 창 6개월).
