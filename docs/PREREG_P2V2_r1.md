## 1. 가설
- **H1 (Q1)**: 6개월 앞(공개 시차 5개월 가정) 성분 원외 청구수량 예측에서 G의 금액 가중 WAPE가 B1·B2·B3 각각보다 작다.
- **H2 (Q2 주)**: origin에 보이는 급여목록 가격 경로(ΔK)를 반영한 단가 예측 U1이 사용통계 단가 추세 U0보다 금액 가중 단가 절대 로그오차가 작다. 처방량이 가격에 반응했다는 주장이 아니다.
- **H3 (Q2-d 보조)**: 목록 정보 보정층 F1q가 F0q′보다 수량 금액 가중 WAPE가 작다. 주입 20%에서 F1q가 '나음'이 아니면 판정하지 않는다.
- **사전 예상**:
  - 기준 3개를 모두 이겨야 하고 T = 36이라 H1 종합은 '판단 보류'가 될 가능성이 높다.
  - δ = 0.5%p에서 EWC 90% 구간 반폭(사전 창 기준 약 1.5 ~ 1.8%p)이 넓어 '동등'은 거의 나오지 않고, 유의하지 않은 결과는 대부분 '판단 보류'가 된다.
  - H3은 '효과를 찾을 힘이 없음'으로 끝날 가능성이 있다.

## 5. 모델 (설정 고정, 튜닝 없음)
- **B0**(참고) = y_a. **B1** = y_{t−12}. **B2** = y_{t−12} · Σ_{k=0}^{11} y_{a−k} / Σ_{k=0}^{11} y_{a−k−12}(24개월 모두 쓸 수 있을 때).
- **B3** = statsmodels ETSModel(log y, 오차·계절 가법, 주기 12, 추세 {없음, 가법 감쇠} 중 AICc 최소, 최대우도 maxiter 1000, 초기값 estimated).
  - 학습 = a에서 끝나는 가장 긴 연속 구간이며 36개월 이상이어야 한다.
  - 추세 두 판 중 하나라도 예외·ConvergenceWarning이면 그 칸은 B2로 대체하고 기록한다.
  - 대체 칸 가중치 몫(Σ_i w_i · 대체 칸 비율)이 10%를 넘으면 G 대 B3는 '판단 보류'다.
- **G** = LightGBM 전역 직접 모델. h마다·origin마다 처음부터 적합한다.
  - 목표 z = log y_τ − log y_{τ−12}, 예측 ŷ_t = y_{t−12} exp(ẑ), 손실 l1.
  - 학습 = 대상 501개, τ ≥ 14 + h열(h = 6이면 2019-09) ~ a.
  - 특징: g1, g3, seas, size, mon(범주), dwork, lunar_t, lunar_b, cls2(범주), cov_base, cov_anchor. 하나라도 계산되지 않으면 그 행을 쓰지 않는다.
  - 하이퍼파라미터: n_estimators 500, learning_rate 0.03, num_leaves 15, min_child_samples 100, max_depth −1, subsample 1, colsample_bytree 1, reg_lambda 1, max_bin 255, deterministic, force_row_wise, n_jobs 1, max_cat_to_onehot 4, random_state = 시드. 학습 행 가중치 없음.
- **Q2 정보**(목록 s = M, A14는 M − 1):
  - ΔK = a·s 모두 급여·목록가 > 0인 같은 제품코드의 log(p_s/p_a) 평균(공통 제품이 없으면 정의 안 됨).
  - ΔN = s월 목록에 남은 R2 토큰(시행일 ∈ (s 1일, t 말일], 집행정지 표시 없음) 중 제품마다 가장 늦은 것 하나. ω·log(예고 금액/p_s), ω = t월 안이면 (t 말일 − 시행일 + 1)/t 일수, 앞이면 1. 이것을 |P_c(s)|로 나눈다.
  - S, SN, LN, ΔF, ΔP의 정의는 DECISIONS 2026-11-20 4단계 표를 따른다.
  - ρ_M = build_asof(M) 원장의 약가 예고 중 check_month ≤ M에서 REALIZED ÷ (REALIZED + REALIZED_LATE + REALIZED_CHANGED + NOT_REALIZED). 분모가 0이면 1.
- **U0** = UP_a (UP_a/UP_{a−12})^{(t−a)/12}, **U1** = UP_a exp(ΔK)(전가율 1).
- **보정층(Q2-d)**: r = log y − log ŷ^G(정직한 롤링 G, h = 6), x = (ΔK, ΔN·ρ_M, ΔF, ΔP, S, SN, LN).
  - 학습 행 = τ ≤ a이고 a′ = τ − 6 ≥ 2022-01인 행. 각 행의 x는 그 행 origin의 목록으로 만든다.
  - 학습 행으로 표준화하고 릿지 λ = 1(절편 벌점 없음)을 쓴다. 분산이 0인 특징의 계수는 0이다.
  - 학습 행 < 501 × 6이거나 x가 정의되지 않으면 F1q = F0q′(기록). F0q′ = ŷ^G exp(학습 잔차 평균).
- **신호(ΔN)는 예측값에 곱하지 않고 보정층 특징으로만 쓴다.**

## 6. 주 지표
- Q1: 금액 가중 WAPE = Σ_i w_i Σ_{t∈E_i} |y_it − ŷ_it| / Y_i = Σ_t d_t.
- Q2 주: Σ_i w_i · mean_{t∈E_i} |log ÛP_it − log UP_it|.
- 헤드라인 = 주 판정 문구 + 전체 기간 지표(B1·B2·B3·G) + 각 차이의 90% 구간(EWC).

## 7. 주 검정과 판정
- 계열 D_t = T(d_t^A − d_t^B), D̄ = 지표 차이.
- **주 검정 = EWC**(Lazarus·Lewis·Stock·Watson 2018):
  - Ω̂ = (1/ν) Σ_{j=1}^{ν} Λ_j², Λ_j = √(2/T) Σ_t cos(πj(t − ½)/T)(D_t − D̄). 통계량 D̄/√(Ω̂/T), 양측 t(ν), α = 0.05.
  - **ν = round(0.4·T^{2/3})**: Q1·Q2 주 T = 36 → 4, Q2-d T = 24 → 3.
  - Ω̂ ≤ 1e-14·mean(D²)이거나 계열에 NaN이 있으면 '판단 보류'(기록).
- **90% 구간** = D̄ ± t_{0.95}(ν)·√(Ω̂/T). 동등(TOST)·헤드라인 모두 이 구간을 쓴다.
- **δ**: Q1·Q2-d = 금액 가중 WAPE 0.5%p, Q2 주 = 로그오차 0.005.
- **판정**(비교 하나마다, 검정 하나):
  - **나음** = p < 0.05, D̄ < 0, R1·R2 평균 모두 < 0
  - **나쁨** = 대칭
  - **기간 의존 — 판단 보류** = p < 0.05이나 R1·R2 부호 조건을 채우지 못함
  - **동등** = p ≥ 0.05이고 90% 구간 ⊂ (−δ, +δ)
  - **판단 보류** = 나머지
  - '나음'이고 90% 상한 > −δ면 "나음(실무 여유 안)"으로 표시한다.
  - R1·R2를 쓰지 않는 비교(Q2-d, 시점 이동 가짜)는 유의하면 부호만으로 판정한다.
- **민감도(판정에 쓰지 않음, 결과와 주 검정과의 차이를 공개)**:
  - ① DM: 가중 없는 지연 0 ~ 5 자기공분산 합, 통계량 × HLN 계수 √((T + 1 − 2h + h(h−1)/T)/T), t(T − 1), 분산 ≤ 0이면 Bartlett 5.
  - ② Bartlett 12, t(T − 1).
  - 각 p와 그 p로 낸 판정 문구(유의성·부호·R1·R2만)를 표에 함께 싣는다.
  - **검정끼리 결론이 달라도 자동으로 판단 보류하지 않는다.**
- **H1 종합**:
  - 세 비교 모두 '나음'이면 "단순 예측보다 나음"이고, 개별 문장은 원 p로 쓴다.
  - 그렇지 않으면 개별 판정을 Holm(3) p로 다시 낸다. 종합은 가장 강한 기준(평가 기간 지표가 가장 작은 B)과의 Holm 판정으로 정한다: 동등 → "가장 강한 기준과 동등", 나쁨 → "가장 강한 기준보다 나쁨", 그 밖 → "판단 보류".
- **H2**:
  - U1 대 U0는 단일 비교이며 보정하지 않는다.
  - 시점 이동 가짜: ΔK를 같은 성분의 7·17개월 앞 origin 값으로 바꾼 판과 비교한다(그 origin의 a ≥ 2022-01인 대상월만, 3개월 미만이면 비교 안 함, R1·R2 없음). 두 판 모두보다 U1이 '나음'이 아니면 "시점 정렬의 기여 확인 안 됨".
  - 순열: 대상월마다 E_Q2 칸 중 ΔK ≠ 0 성분끼리 ΔK를 섞어 999회 돌린다. 지표는 평가 기간 전체 Q2 지표이고, p = (1 + #{순열 ≤ 실제})/1000이다. p ≥ 0.05면 "성분별 정렬의 기여 확인 안 됨".
- **H3**:
  - 주입: 성분의 목록 가격지수가 처음 내려간 목록월 이후 처방월의 수량·금액에 (1 − δ)를 곱한다(δ = 5·10·20%, 첫 번만). G와 보정층을 처음부터 다시 적합하고, 평가 칸은 원래 Q2-d 칸을 쓴다.
  - δ = 20%에서 F1q가 F0q′보다 '나음'이 아니면 "효과를 찾을 힘이 없음"으로 보고 실제 결과의 '개선 없음'을 해석하지 않는다.
  - 회수율 = (WAPE_F0q′ − WAPE_F1q) ÷ (WAPE_F0q′ − WAPE_F0q′(주입 없는 자료)).
- **참고용 사전 검출력**(판정 근거 아님, 사용통계 ≤ 2022-12, 사전 창 2020-06 ~ 2022-12): EWC 기준 단일 비교 '나음' 비율은 참 ΔWAPE 0에서 2.4 ~ 2.8%, −0.5%p에서 6.1 ~ 7.3%, −1.0%p에서 13.1 ~ 18.0%다. B2 단독·B2 − B1 두 계열이 비슷하다(`outputs/p2v2/power_ewc.csv`). DM 기준 결과(`power.csv`)는 보존한다. 어느 쪽도 주 검정으로 올리지 않으며, 검출력으로 판정 규칙을 바꾸지 않는다. Q2 검출력은 미산정(사전 창 6개월).

## 8. 보조 분석 (닫힌 목록, 판정에 쓰지 않음)
- A1 연도별(2022 회복기 행 포함), A2 성분별 WAPE 비 G/B(기하평균·중앙값·< 1 비율), A3 편향 Σ_i w_i Σ_t(ŷ − y)/Y_i, A4 H(가중치 다시 정규화).

## 9. Stage 4 (2026-01 ~ 06, 한 번만, **Q1만**)
- **범위**: Q1 비교(G 대 B1·B2·B3)만 한다. **Q2 Stage 4는 이번 범위에서 하지 않는다.** 2026 목록 처리와 그 접근 예외를 승인하지 않았고, 후속 과제로 분리했다(사용자 결정 2026-11-20).
- **전제(`stage4.guard`)**:
  - 이 태그와 잠금 파일이 일치해야 한다.
  - `reports/P2V2_backtest_result.md`가 HEAD에 커밋되어 있어야 한다.
  - 정답 적재·채점은 예측 봉인 태그 `p2v2-stage4-forecasts`도 있어야 한다.
  - CLAUDE.md의 Stage 4 예외는 이 조건 아래에서만 쓴다.
- **순서**:
  1. 파일 기록(경로·크기·SHA-256·수정 시각)
  2. 형식 점검(헤더·STD_YYYYMM·OUT_IN_HOS 값만, 청구 값은 읽지 않음, 새 칸·코드면 멈춤)
  3. 예측(B1·B2·B3·G, a = 2025-07 ~ 12, h = 6, 입력 사용통계는 `data/raw` 2018 ~ 2025 판만) → 봉인 태그
  4. 정답 적재(2026 사용통계 원외 × 성분4 × 월, 정답으로만)
  5. 채점
- **채점(p값 없음)**:
  - 비교마다 달별 d_t, 6개월 합 ΔWAPE, 백테스트 방향과 부호가 같은 달 수를 낸다.
  - 백테스트가 '나음'·'나쁨'인 비교는 합의 부호가 같고 4개월 이상 같으면 '반대 방향 아님', 아니면 '반대 방향'이다.
  - 그 밖의 비교는 점추정 부호 일치만 보고한다.
  - 2023 ~ 2025 오차 수준과 비교하지 않는다.
- **확정 채점**: 모든 대상월이 첫 공개 후 12개월 지난 판(2027-11 이후 받는 판)으로 같은 봉인 예측을 다시 채점한다.

## 10. 잠금과 이탈
- **실행 잠금**:
  - `make p2v2-backtest`는 태그 `p2v2-prereg-r1` 시점의 잠금 파일과 작업 트리 잠금 파일의 내용 해시가 같을 때만 주 결과를 낸다(`outputs/p2v2/backtest/`).
  - 다르면 `--deviation`으로만 '사전등록 이탈' 판을 낸다(`outputs/p2v2/deviation_<해시>/`).
  - 태그가 없으면 어떤 판도 실행하지 않는다.
  - 실행마다 `outputs/p2v2/run_log.csv`에 기록한다.
- **잠금에서 뺀 것**: 검증 스크립트 `dryrun.py`·`p2v2_ewc_check.py`(실제 분석 결과에 영향 없음, 해시는 §0에 보존, 변경은 DECISIONS에 기록). 문서·보고서(`docs/`, `reports/`)는 잠그지 않는다.
- **바꾸지 않는 것**: §2 ~ §9 전부.
- **태그 뒤 버그 수정**:
  - 원판 결과를 주 결과로 남긴다.
  - 수정판과 판정이 갈리면 결론은 '판단 보류'다.
  - 모든 태그 뒤 diff를 보고서 부록에 싣는다.
  - 이탈판은 r2(`p2v2-prereg-r2`)부터 쓰고 DECISIONS에 적는다.
