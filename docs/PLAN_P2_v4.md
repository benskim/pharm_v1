# PLAN P2 v4 — 근무일수 보정 ETS(①)와 성분별 예측 구간(②)

> 상태: **설계 확정(2026-11-24 사용자 결정, §11).** 코드·시험·동작 확인까지 하고 본 실행 전에 멈춘다. 본 실행은 태그 `p2v4-prereg-r1` 뒤에만.
> P2 v2의 판정·봉인 예측·잠금 코드, P2 v3의 종료 결론은 바꾸지 않는다. 2026 자료는 읽지 않는다.

## 0. 목적 · 성공 기준 · 기대 결과

**목적**: 운영 권고 모델 ETS(B3)가 쓰지 않는 달력 정보를 넣고(①), 예측값 하나 대신 성분마다 '얼마나 틀릴 수 있는가'를 구간으로 낸다(②).

| | 질문 | 성공 기준 (실행 전 고정) | 기대 결과 |
|---|---|---|---|
| ① | 근무일수 보정 ETS(W)가 ETS(B3)의 달력 오차를 없애는가 | **S1** D̄(W − B3) < 0, R1·R2도 < 0 **그리고 S2** 월 공통 오차와 dw의 상관이 \|r_W\| ≤ 0.3이고 \|r_W\| < \|r_B3\| | S2는 통과 가능성이 높다. S1의 크기는 1%p 미만일 것이다 |
| ② | 성분별 폭(I1)이 공통 폭(I0)보다 나은가 | **C1** 90% 구간 포함률이 전체 87 ~ 93%, 연도마다 85 ~ 95% **그리고 C2** 90% 구간 점수 I1 − I0의 판정 '나음'(§6) | C2는 통과 가능성이 높다. **C1은 2023에서 실패할 수 있다**(보정 자료가 코로나 회복기) |

- 성공은 ①·②를 **따로** 적는다. 하나의 실패가 다른 하나의 결과를 바꾸지 않는다.
- ①의 공식 판정('나음'·'동등'·'판단 보류' 등)은 성공 여부와 별도로 함께 적는다. 36개월로는 0.5%p 차이의 검출 비율이 약 6 ~ 7%(P2 v2 사전 시뮬레이션)다. ①이 성공해도 판정이 '나음'이 아니면 "ETS보다 낫다"가 아니라 **"달력 누락을 고친 ETS이고 점추정이 작았다"**고만 쓴다.
- 모두 실패해도 그대로 보고하고 닫는다. 설정을 바꿔 다시 돌리지 않는다.

## 1. 신호 ↔ 설계 대조표

아래 수치는 2026-11-24 진단 값이다. P2 v2 백테스트 예측(h = 6, 2023 ~ 2025, 16,486칸)을 읽기 전용으로 분해했고, 저장소 산출물이 아니므로 **실행 때 다시 계산**한다(§7 X1).

| 찾은 신호 | 진단 값 | 쓰는 곳 | 쓰는 방식 |
|---|---|---|---|
| 월 공통 오차와 dw의 연관 | B3 −0.64, B1 −0.60, G −0.10 | **①** | 근무일수 효과를 빼고 ETS 적합, 예측 달에 되돌림 |
| 성분별 절대오차 크기의 지속 | 이웃한 해 순위상관 0.79 ~ 0.83 | **②** | 성분별 척도 σ_i |
| 부호 오차는 지속되지 않음 | 6 ~ 8개월 전 평균과 −0.02 | ② | 구간을 로그 척도에서 **대칭**으로 둠. 편향 보정 없음 |
| 약효군 × 월 공통 충격 | 제거 이론 상한 G 6.51% → 4.79% | 쓰지 않음 | 6개월 앞에서 보이는지 모름. 포함률의 월별 쏠림만 보고(X5) |
| G·ETS 50:50 평균의 점추정 | 6.05% | 쓰지 않음 | 보류 결정(E1g, 2026-11-24)과 같은 사후 선택 |

dw = 대상월 근무일수 − 전년 같은 달 근무일수. **비교 모델이 이미 쓰는 정보**: G는 dw와 설·추석을 이미 특징으로 쓴다. 그래서 ①은 G가 아니라 **B3의 개선**을 묻는다. 새 정보를 찾는 실험이 아니다.

## 2. 먼저 적는 한계 (보고서 첫 줄에 그대로)
- **맹검이 아니다.** 평가 기간 2023-01 ~ 2025-12는 P2 v1 ~ v3가 보았고, ①·②의 착안도 같은 기간 오차에서 나왔다. 결과는 낙관 쪽으로 기울 수 있다. 확증은 새 자료로만 할 수 있다.
- 수정본 사용통계로 평가한다. 최근 달은 덜 집계되었을 수 있다.
- 구간은 **관측된 칸**에 대한 것이다. 비공개로 미관측이 될 위험은 담지 않는다.
- 전국 성분 단위 원외 처방이다. 약국 재고 구간이 아니다.

## 3. 고정하는 것 (P2 v2와 같음)
대상 501개와 가중치 w, 원외 청구수량, origin M, 입력 ≤ a = M − 5, **h = 6**, 평가 대상월 2023-01 ~ 2025-12(T = 36), 금액 가중 WAPE, B3의 정의. `src/pbd/forecast_v2/`는 고치지 않고 불러 쓴다. 공개 시차는 5개월 가정 하나만 쓴다.

## 4. 달력

1. **근무일수** = 평일 중 공휴일이 아닌 날(`calendar_kr.workdays`, 토요일 제외).
2. **목록 점검 상태**: `kr_holidays`와 `HOLIDAYS_KR_CHECKLIST.md`의 2018 ~ 2025 날짜 145일이 **모두 같다**(2026-11-24 확인). 단 체크리스트는 출처 대조 전 초안이므로 **공식 출처 검증은 아니다**(확인 3c는 열려 있다).
3. **새로 찾은 위험 — 임시공휴일 미리보기**: 임시공휴일은 늦게 지정될 수 있어 origin M에는 몰랐을 수 있다. 체크리스트의 임시공휴일은 2020-08-17, 2023-10-02, 2024-10-01, 2025-01-27, 2025-06-03이다. 지정일 자료는 저장소에 없다.
   - **주 정의 wd_known**: 예측 달 t에서는 임시공휴일을 **모른다고 보고 근무일로 센다**. 이력 달(≤ a)에서는 실제 달력을 쓴다. 지정일을 알 필요가 없는 보수적 규칙이다(2025-06-03도 포함).
   - 민감도 **W-all**: 예측 달에도 모든 공휴일을 쓴다(G의 dwork와 같은 달력).
   - 이력 달이란 a = M − 5 이하이므로 그때의 임시공휴일은 이미 지나간 날이다.
   - G의 dwork에도 같은 미리보기가 있다. P2 v2 결과는 바꾸지 않는다. LIMITATIONS에 적을지는 §11-3.

## 5. 실험 ① 근무일수 보정 ETS

| ID | 내용 | 역할 |
|---|---|---|
| **B3** | P2 v2 ETS | 기준 |
| **W** | 성분별 계수(전체 쪽으로 줄임), wd_known | **주 비교 W 대 B3** |
| Wg | 모든 성분에 계수 하나 | 보조(줄임의 몫) |
| W-all | W와 같고 예측 달에 임시공휴일 포함 | 민감도(적합은 W와 공유) |

**계수 추정 (origin a마다, ≤ a만)**
1. z_{i,t} = log y_{i,t} − log y_{i,t−12}, dw_t = 근무일수_t − 근무일수_{t−12}.
2. 느린 추세·수준 이동을 없애려고 한 번 더 차분: u = z_t − z_{t−1}, v = dw_t − dw_{t−1}. 네 달 모두 관측·> 0인 행만. 절편 없음.
3. 성분별 β̂_i = Huber 회귀 u ~ v(조정상수 1.345, MAD 척도), 유효 행 24개 이상. 미만이면 전체 값.
4. 전체 값 β̄ = 성분 β̂_i의 DerSimonian–Laird 평균, β_i = b_i·β̂_i + (1 − b_i)·β̄, b_i = τ² ÷ (τ² + se_i²). 군은 쓰지 않는다(P2 v3에서 이득이 없었다). Wg는 β_i = β̄.
5. 코로나 기간도 행에서 빼지 않는다. 첫 origin에서 코로나 밖 행이 너무 적기 때문이다. Huber로 극단값 영향을 줄인다. 같은 달 성분들은 독립이 아니므로 **se_i를 계수의 유의성 근거로 쓰지 않는다**.

**적합과 예측**
- c_t = 근무일수_t. 이력은 x_t = log y_t − β_i·c_t에 B3와 **같은 ETS 코드·같은 후보·같은 선택 규칙**을 적용한다.
- 예측 ŷ_t = exp(x̂_t + β_i·c_t^known). 계절 성분이 같은 달 평균 근무일수를 이미 담으므로, 바뀌는 것은 그 해 달력의 차이다.
- `ets_path`는 양수 수량을 받으므로 exp(x_t)를 넣는다. 지수 범위를 벗어나지 않게 c_t에서 22를 뺀 값을 쓴다(계절·수준에 흡수되어 예측은 같다).
- 대체 규칙은 B3와 같다. ETS 적합이 실패하면 B2 값. 대체 칸 가중치 몫이 10%를 넘으면 '판단 보류'.
- β_i에 상한·하한을 두지 않는다. 분포만 보고한다(X2).

## 6. 실험 ② 성분별 예측 구간

**중심 예측**: ①이 성공 기준 S1·S2를 모두 만족하면 W, 아니면 B3. 두 경우 모두 계산하고, 선택되지 않은 쪽은 보조로 둔다.

**보정 자료 (origin a마다)**: 이미 정답이 나온 과거 h = 6 예측의 s_{i,τ} = |log(y_{i,τ} ÷ ŷ_{i,τ})|, τ ∈ [a − 23, a](24개월, τ를 예측했던 origin의 예측 그대로). 계수 추정에 24행이 필요해(§5의 3) 가장 이른 τ는 2021-07이다(초안의 2021-06은 이중 차분 뒤 23행뿐이라 동작 확인에서 실패해 고침). 따라서 **첫 평가월은 보정 13개월, 24개월이 차는 것은 대상월 2023-12(a = 2023-06)부터다.**

| ID | 구간 |
|---|---|
| **I0** | ŷ·exp(±q), q = 보정 자료 전체 s의 분위. 모든 성분에 같은 폭 |
| **I1** | ŷ·exp(±q·σ_i), q = 척도로 나눈 s_{i,τ} ÷ σ_i^{(−τ)}의 분위 |
| I-year (보조) | 작년 같은 달을 중심으로 I0 방식. 단순 기준 |

- σ_i = 보정 자료의 성분 평균 s를 로그 척도에서 전체 평균 쪽으로 경험적 베이즈로 줄인 값(군 없음). 관측 6개월 미만이면 전체 값.
- q를 구할 때는 그 달을 뺀 σ_i^{(−τ)}를 쓴다. 같은 자료로 척도와 분위를 함께 정하면 구간이 좁아지기 때문이다.
- 분위 = ⌈(n + 1)·(1 − α)⌉번째 값. 성분 안·달 안 의존 때문에 **포함률의 이론 보장은 없고, 실측으로만 평가**한다.
- 수준: **90%(주)**, 80%(보조). 평가 칸은 ①과 같다.

**지표**
- 포함률(주 C1) = 비가중 칸 비율. 금액 가중 포함률은 보조.
- 구간 점수(주 C2, 로그 척도, 작을수록 좋음) IS = (U − L) + (2/α)(L − x)·1[x < L] + (2/α)(x − U)·1[x > U], x = log y. 두 끝 분위의 pinball loss 합에 2/α를 곱한 값과 같다.
- 성분 i의 평균 IS를 w_i로 가중하고 대상월로 분해해 D_t를 만든다(WAPE와 같은 방식).
- C2 판정 '나음' = EWC(ν = 4) p < 0.05, D̄ < 0, R1·R2 부호도 < 0. '동등' 여유는 두지 않으며 나머지는 '나쁨'·'기간 의존'·'판단 보류'로 적는다.

**위험 등급(운영 제안, 판정 아님)**: origin 시점의 90% 반폭(위쪽 exp(qσ_i) − 1)으로 낮음 < 10%, 중간 10 ~ 30%, 높음 ≥ 30%. 30%는 기존 예외 플래그와 맞춘 **가정값**이다. 지금 쓰는 플래그(평가 기간 자료로 정함)를 예측 시점 이전 자료만 쓰는 규칙으로 바꾼 것이다.

## 7. 평가와 보조 (닫힌 목록)
- 평가 칸 = P2 v2 E_Q1 ∩ {W, Wg, W-all 예측 있음, I0·I1 정의}. 공통 집합 하나. 빠진 칸은 `outputs/audit/dropped_p2v4_*.csv`.
- ①의 D_t·EWC·δ = 0.5%p·R1(2023 제외)·R2(2024-11 ~ 2025-12 제외)·판정 표는 P2 v2 §5-8 그대로. 주 비교는 W 대 B3 하나, C2는 ②의 주 비교 하나다. 서로 다른 질문이라 각각 α = 0.05, Holm 없음.
- S2의 월 공통 오차 = Σ_i v_i y_{i,t} log(ŷ ÷ y) ÷ Σ_i v_i y_{i,t}, v_i = w_i ÷ Σ_{t∈E_i} y_{i,t}. dw는 **실제 달력**을 쓴다.

| ID | 보조 |

| X1 | §1 진단 값 재계산(B3·G·B1) |

| X6 | 위험 등급별 성분 수, 가중치 몫, 실제 오차, 포함률 |
| X7 | 임시공휴일이 든 대상월을 뺀 W 대 B3 |

## 8. 누설 방지 (시험으로 확인)
1. origin a에서 a 뒤의 정답·예측을 바꿔도 β_i, σ_i, q, 예측, 구간이 그대로다.
2. 예측 달 달력에서 임시공휴일을 지우거나 더해도 W 예측이 그대로다(W-all은 바뀐다).
3. 2026 처방월이 입력에 있으면 멈춘다.

손 계산 시험(기대값은 합성 자료): β 알려진 계열에서 β 회수, 줄임(se가 크면 β̄), 근무일수가 매년 같으면 W = B3, 분위 순번, 구간 점수, 달 빼기 σ, 태그 없으면 본 실행 거부.
