## 5. 문서와 달랐던 점 / 발견

1. **V6 결함 발견·수정**: 상수 계열에서 부동소수점 잔차로 Ω̂ ≈ 1e-36 > 0이 되어 invalid로 걸러지지 않았다(시험 `test_v6_constant_series_is_hold` 실패). 문턱을 Ω̂ ≤ 1e-14 · mean(D²)로 두고 고쳤다(DECISIONS 기록). 수정 뒤 V6 시험 3개 통과.
2. V2에 **T = 24, ν = 3 행을 추가**했다(Q2-d 평가 기간, ν 규칙 승인에 따라). 승인한 V2 기준을 그대로 적용했고 결과는 통과다.
3. T = 24의 R1·R2 위치: Q2-d 평가 기간(2024-01 ~ 2025-12)에는 2023이 없으므로 R1 = 전체, R2 = 2024-01 ~ 2024-10으로 두었다. PLAN이 Q2-d의 R1·R2를 따로 정하지 않았다 → 확인 필요 2.
4. '나음' 비율이 한쪽 거짓 양성과 거의 같다(R1·R2 조건이 크기를 거의 줄이지 않음). 정상 계열에서는 전체 평균이 유의하게 음수면 부분 기간 평균도 대부분 음수이기 때문이다.

## 6. 확인 필요

1. **EWC ν = 4 주 검정 승인 여부.** 승인 기준 V1 ~ V3·V6은 모두 통과했다. 승인하면 남는 일은 다음과 같다(모두 다음 지시 때).
   - (a) 사전등록 문서에 주 검정·민감도·구간·판정 규칙 반영
   - (b) 3단계 검출력 표를 EWC 기준으로 다시 산출(기존 DM 결과는 민감도로 보존)
   - (c) 참고용 검출력 두 계열(S_B2·S_DIFF) 기록(이전 결정 4)
2. **Q2-d(T = 24)의 R1·R2**: 위 3번처럼 둘지, Q2-d에는 R1·R2 조건을 두지 않을지.
3. **Q2 주(U1 대 U0)·Stage 4의 검정**: Q2 주는 T = 36이라 ν = 4가 된다. Stage 4는 p값을 참고로만 쓴다. 두 경우 모두 EWC를 같은 규칙으로 쓰는 것으로 이해했다. 맞는지.
