## 4. dry run

**합성 세계**: 성분 24개 × 2018-01 ~ 2025-12, 잡음 없음.
- 수량은 성분별 연 성장률 g_i와 달 계절성만으로 만들었다. 그래서 B2는 정확하고(오차 0), B1 오차는 1 − 1/g_i다.
- 성분별 목록가는 L_i월에 d_i ∈ [0.80, 0.95]배로 내리고, 단가도 그만큼 따라간다(전가율 1).
- 미리 넣은 상황: 미관측 1칸(+ 재등장 첫 달), 수량 0 1칸, 집행정지 1성분.

**손 계산 대조(생성식에서 직접 계산, 파이프라인 예측을 쓰지 않음)**: 대상 24, 가중치(최대 차이 0), 평가 칸 822, B0 WAPE 12.68%, B1 3.86%, B2 0, Q2 U1 지표 0.002606, U0 0.029741, ΔN(집행정지 성분 0), 첫 하락 달 = L_i, EWC ν 4·3, 순열 p < 0.05 — 모두 일치.

**합성 자료에서 나온 판정**(파이프라인이 끝까지 도는지 확인용, 실제 결과와 무관):
- Q1 종합 "가장 강한 기준보다 나쁨". B2가 정확하므로 기대한 결과다.
- G 대 B1은 '나음', G 대 B3은 '나음(실무 여유 안)'이다.
- 판정 문장과 표의 모든 열이 채워진다. 민감도(DM·B12)와 주 검정의 결론 비교 줄도 나온다.
- Q2 주는 '나음', 가짜 7·17개월 모두 '나음', 순열 p = 0.005다.
- Q2-d는 '동등'이다(합성 수량에 가격 반응이 없음). 주입 5·10·20%는 모두 '나음'이고 회수율은 0.44·0.46·0.41이다.
- 보조 A1 ~ A18 표 106행(A8·A9는 아래 5-3).

## 5. 발견하고 고친 것 / 문서와 달랐던 점

1. **순열 퇴화(합성 자료)**: 처음 합성 세계는 모든 성분의 인하 폭이 10%로 같아, ΔK를 섞어도 바뀌지 않아 p = 1이었다. 코드 결함이 아니라 정의대로의 결과다(설계 검토 33). 인하 폭을 성분마다 다르게 바꾼 뒤 p = 0.005가 나왔다. 시험 `test_permutation_degenerate_when_all_equal`로 이 성질을 고정했다. 실제 자료는 ΔK가 성분마다 다르다(a = 2022-06 점검에서 ΔK ≠ 0인 성분 113개, 값 −0.36 ~ +0.41).
2. **Q1 종합 문구의 p(사용자 확인 필요)**: 종합이 '나음'이 아닐 때 "가장 강한 기준과 …" 문장을 원 p 판정으로 내고 있었다. 그래서 개별 표(Holm 3)와 어긋날 수 있었다. 가장 강한 기준은 결과로 고르는 것이라 Holm 판정을 쓰도록 고쳤다. 시험을 추가했다(원 p 0.04 → Holm 0.06 → '판단 보류'). DECISIONS·변경 이력 C9.
3. **A8(96개월 부분집합)·A9(2022 가중치)는 dry run에서 실행하지 않았다.** 가중치 배열을 넣으면 A4와 같은 표 함수로 돈다. 그러나 합성 자료에서 그 경로를 따로 돌리지 않았다.
4. PLAN이 이름만 정한 정의(ΔN 토큰 선택, S·SN·LN·ΔF·ΔP, ρ_M 분모, 가짜 비교의 R1·R2, 순열 단위, 주입 배율, 보조 분석 세부)를 정해 DECISIONS 4단계 표와 변경 이력 C1 ~ C8에 적었다.
